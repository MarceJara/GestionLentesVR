# README - Sistema de Gestión de Lentes VR

## Descripción
Sistema web tipo dashboard para la gestión integral de lentes de realidad virtual. Permite administrar aplicaciones de instalación, actualizaciones de firmware y monitoreo de dispositivos, desarrollado bajo arquitectura en capas.

## Tecnologías
- Backend: Java
- Frontend: HTML, CSS, JavaScript, C#
- Base de datos: SQL

## Estructura del Proyecto
src/<br>
├── dominio/         # Entidades principales del sistema<br>
├── persistencia/    # Acceso a datos (DAO)<br>
├── logica/          # Lógica de negocio<br>
└── presentacion/    # Interfaces de usuario<br>

## Principales Funcionalidades
- Gestión de dispositivos VR
- Instalación/desinstalación de aplicaciones
- Actualizaciones de firmware
- Monitoreo en tiempo real
- Configuración personalizada de audio
- Generación de reportes
- Sistema de alertas y notificaciones

## Requisitos del Sistema
- JDK 11 o superior
- .NET Framework 4.7+ (para componentes frontend)
- Servidor SQL
- Navegadores modernos (Chrome, Edge, Firefox)

## Instalación
1. Clone el repositorio
2. Configure la base de datos según los scripts proporcionados
3. Compile el proyecto usando Maven o su IDE preferido
4. Despliegue la aplicación en un servidor web

## Instrucciones para Desarrolladores
- Siga la arquitectura en capas para nuevos desarrollos
- Utilice programación orientada a objetos
- Documente los cambios siguiendo el estándar JavaDoc
- Implemente pruebas unitarias para nuevas funcionalidades
